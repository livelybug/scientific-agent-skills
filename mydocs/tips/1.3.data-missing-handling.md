# MICE, Multiple Imputation by Chained Equations

* 它的核心思想是：不孤立地看待每一个缺失值，而是利用数据集中其他所有列的信息，通过迭代的方式，把每一列的缺失值“预测”出来。

### ⚙️ 核心工作原理：MICE 算法

`IterativeImputer` 并不是简单地用均值或中位数去填充，而是遵循以下迭代逻辑：

1. **初始填充**：首先，用简单的统计量（如均值或中位数）对所有缺失值进行初步填充，得到一个“临时”的完整数据集。
2. **逐列迭代**：接着，算法会轮流把每一列当作“目标变量”（即假装这一列有缺失），把其他所有列当作“特征变量”。
3. **建模预测**：利用当前其他列的完整数据，训练一个回归模型（这就是**估计器 estimator**），来预测当前目标列的缺失值。
4. **循环收敛**：用预测值更新缺失值后，再处理下一列。当所有列都处理完一遍，就完成了一轮迭代。这个过程会反复进行（由 `max_iter` 参数控制），直到插补的值趋于稳定（收敛）。

### 📊 估计器选择对比

| 估计器类型 | 适用场景 | 核心优势 |
| :--- | :--- | :--- |
| **BayesianRidge** (默认) | 变量间主要为线性关系，或存在多重共线性 | 稳健、计算快、不易过拟合 |
| **RandomForest** | 变量间存在复杂的非线性关系或交互作用 | 自动捕捉复杂模式、对异常值不敏感 |

### 💡 实际应用建议

1. **从默认开始**：在大多数情况下，直接使用默认的 `BayesianRidge` 就能获得不错的结果。
2. **尝试进阶模型**：如果你怀疑数据中存在复杂的非线性关系，或者你的特征维度很高，可以尝试将估计器换成 `RandomForestRegressor`。

# 把缺失值作为模型参数联合采样

**1. 核心机制：把缺失值作为模型参数联合采样**
在传统的数据处理中，我们通常会先“填补缺失值”（Imputation），然后再把填补好的数据丢进模型里分析。这其实是割裂的两步。
而在 PyMC 的贝叶斯框架下，缺失值不再是需要被“修复”的瑕疵，而是被视为**未知的模型参数**。这意味着，在模型进行马尔可夫链蒙特卡洛（MCMC）采样时，模型会同时估计两类东西：一是我们关心的模型参数（如回归系数），二是那些缺失的值。缺失值的填补与模型的参数估计是在同一个推理过程中“联合”完成的，它们会互相影响、互相提供信息。

**2. 核心优势：不确定性量化 (HDI)**
传统的单一填补法（比如用均值或回归预测值填充）最大的问题是，它假装填补的值就是绝对真实的值，从而低估了数据的不确定性。
PyMC 通过联合采样，最终得到的不是一个单一的填补值，而是缺失值的**后验概率分布**。通过计算最高密度区间（HDI, Highest Density Interval），我们可以直观地看到缺失值最可能落在哪个范围内，以及有多大的把握。这种对不确定性的完整量化，至关重要。

**3. 适用前提：适合 MCAR/MAR 假设且需要可信区间的科学场景**
*   **MCAR/MAR 假设**：这种方法在数据“完全随机缺失 (MCAR)”或“随机缺失 (MAR)”的机制下表现最为稳健。也就是说，数据缺失的概率与未观测到的值本身无关（如果是 MNAR，即非随机缺失，则需要更复杂的建模来处理缺失机制本身）。
*   **科学场景**：在医学、心理学、生态学等科学研究中，研究者不仅需要知道“结果是什么”，更需要知道“结果的可信度有多高”。PyMC 提供的不仅是点估计，更是包含完整不确定性信息的后验分布和可信区间。
