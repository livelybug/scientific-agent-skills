# reference-only

在这个 EDA skill 里有**三层明确含义**：

## 1. 字段层面：tier 标签

[`skills/exploratory-data-analysis/scripts/_capabilities.py:155-167`](skills/exploratory-data-analysis/scripts/_capabilities.py#L155-L167) 的 `_reference()` 工厂函数把每个 reference-only 后缀打上 `"tier": "reference_only"`，并显式声明依赖：

```python
"tier": "reference_only",
"dependency": "manual or separately validated domain tooling",
```

→ **字面意思：手册里有名字，但脚本里没有解析器。**

## 2. 策略层面：明确"不支持可执行"

[`skills/exploratory-data-analysis/scripts/capability_manifest.py:85-90`](skills/exploratory-data-analysis/scripts/capability_manifest.py#L85-L90) 的 `policy` 字段里有一句关键声明：

```python
"reference_only_means_executable_support": False,
```

→ **关键澄清：reference-only ≠ 弱支持，而是"完全没有可执行支持"**。手册里有这个格式的章节，但 bundled 的 `eda_analyzer.py` 不会、也**不能**处理它。

## 3. 行为层面：硬拒

[`skills/exploratory-data-analysis/scripts/eda_analyzer.py:175-180`](skills/exploratory-data-analysis/scripts/eda_analyzer.py#L175-L180)：

```python
if capability["tier"] == "reference_only":
    raise CliError(
        "this is a documented reference-only format; use validated domain "
        "tooling or convert a copy to an automated format"
    )
```

→ **行为上：`eda_analyzer.py` 看到 reference-only 后缀会直接抛 `CliError` 退出，不做任何分析。**

## 那 reference-only 的"用途"是什么？

[`skills/exploratory-data-analysis/SKILL.md:92`](skills/exploratory-data-analysis/SKILL.md#L92) 写得很清楚：

> | …Parquet/Excel/… SAM/BAM/… | **Reference-only** | Read the matching reference and use separately pinned/validated domain tooling or convert a **derived copy** to an automated format |

两个出路：

1. **看手册 → 找外部工具**：`skills/exploratory-data-analysis/references/*.md` 里为每个 reference-only 格式写了一段"用哪个外部工具、按什么 policy 处理"的指南（比如 SAM/BAM 让你用 pinned SAM/BAM validator，DICOM 提醒你 PHI 政策，VCF 用 pinned VCF validator 等）。这层意义是**知识库**。
2. **转格式**：把数据先转成 automated 后缀的派生副本（例如 Parquet → CSV、mzML → TSV 摘要），再回来走 `eda_analyzer.py`。

## 一句话总结

> **"reference-only" = "skill 知道这个格式叫什么、有什么坑，但不会替你解析它；要解析，请用手册指引的外部 pinning 工具，或自己转成 automated 格式。"**

它不是"次要支持"，不是"降级版自动化"，是**显式的、有手册指引的、强制 fail-closed 的"无解析器"声明**。这层含义写在 `policy.reference_only_means_executable_support = False` 和 `eda_analyzer.py` 的硬拒错误里。
